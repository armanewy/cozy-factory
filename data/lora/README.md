This folder is intentionally empty. If you choose to train an optional LoRA
for style locking, place your dataset under a subfolder like
`data/lora/cozy_sticker_v1/` with an `images/` directory and optional
`captions.json` as described in `docs/LoRA_TRAINING.md`.

No third‑party or exploratory image assets are kept in the repository to avoid
confusion with the final game art in `assets/art/cards/`.
